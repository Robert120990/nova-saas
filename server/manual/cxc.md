# Cuentas por Cobrar (CXC)

Gestión de cuentas por cobrar a clientes.

## Requisitos
- Permiso: `view_customer_statement`
- Permiso: `manage_cxc_payments`

## Consulta de Cliente

1. Vaya a **Cuentas por Cobrar > Consulta de Cliente**
2. Seleccione el cliente
3. Visualice:
   - **Saldo actual** del cliente
   - **Documentos pendientes** con montos y fechas de vencimiento
   - **Historial de pagos** realizados
   - **Detalle de cada factura** (número, fecha, monto, saldo)

## Abonos / Pagos

### Registrar un abono

1. Vaya a **Cuentas por Cobrar > Abonos / Pagos**
2. Seleccione el **cliente**
3. Seleccione la(s) **factura(s)** a pagar
4. Ingrese el **monto** del abono
5. Seleccione el **método de pago**: Efectivo, Cheque, Transferencia, Tarjeta
6. Opcionalmente ingrese **observaciones**
7. Confirme el pago

**Nota:** Puede aplicar un pago a múltiples facturas y el sistema distribuirá el monto automáticamente.

## Reportes

### Saldos de Clientes
- Listado de todos los clientes con saldo pendiente
- Totales agrupados
- Filtros por rango de saldo

### Documentos Pendientes
- Detalle de cada documento por cobrar
- Fecha de emisión y vencimiento
- Días de mora
- Saldo actual
