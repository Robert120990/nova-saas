# Recursos Humanos

Gestión de empleados, planillas y catálogos de RRHH.

## Requisitos
- Permisos específicos para cada submódulo

## Empleados

### Registrar un empleado

1. Vaya a **Recursos Humanos > Empleados**
2. Haga clic en **Nuevo Empleado**
3. Complete los datos personales:
   - Nombre completo, DUI, NIT, NUP (Número Único Previsional)
   - Fecha de nacimiento, nacionalidad
   - Estado civil, dirección, teléfono, email
4. Datos laborales:
   - Tipo de contrato
   - Fecha de ingreso
   - Cargo / puesto
   - Departamento
   - AFP, ISSS
   - Salario
   - Jornada laboral
5. Contactos de emergencia
6. Guarde

### Editar empleado
- Actualice datos personales y laborales
- Historial de cambios salariales

## Planillas

### Vacaciones
1. Vaya a **Recursos Humanos > Planilla Vacaciones**
2. Seleccione el período
3. El sistema calcula automáticamente:
   - Días de vacaciones según ley
   - Monto a pagar
4. Confirme la planilla

### Planillas ordinarias
1. Vaya a **Recursos Humanos > Planillas**
2. Seleccione el período de pago
3. El sistema procesa automáticamente:
   - Salarios calculados por día/hora
   - Descuentos de AFP, ISSS, ISR
   - Descuentos programados (embargos, préstamos)
   - Horas extras y bonificaciones
4. Revise y confirme

### Aguinaldos
1. Vaya a **Recursos Humanos > Planilla Aguinaldos**
2. Seleccione el año
3. Calcule según reglas por año calendario
4. Confirme

### Liquidaciones
1. Vaya a **Recursos Humanos > Planilla Liquidaciones**
2. Seleccione el empleado
3. El sistema calcula:
   - Indemnización
   - Vacaciones proporcionales
   - Aguinaldo proporcional
4. Confirme y genere

### Honorarios y Servicios
- Registro de pagos por servicios profesionales
- Retención de ISR según corresponda

## Catálogos de RRHH

Administre catálogos necesarios para las planillas:
- **AFPs** — Datos de las administradoras de fondos de pensiones
- **Cargos** — Catálogo de puestos
- **Descuentos Programados** — Descuentos fijos recurrentes
- **Departamentos** — Estructura organizacional
- **Porcentajes AFP** — Tasas vigentes (empleado + empleador)
- **Porcentajes ISSS** — Tasas vigentes
- **Renta (ISR)** — Tablas de retención por tramos
- **Aguinaldo** — Configuración de reglas
- **Salario Mínimo** — Montos vigentes por rubro
- **Tipos de Contrato** — Plazo fijo, indefinido, etc.
- **Cuentas de Planillas** — Configuración contable
