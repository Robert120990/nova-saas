# Dashboard

La página principal del sistema muestra indicadores clave (KPI) del negocio en tiempo real.

## Componentes del dashboard

### Tarjetas de resumen
- **Ventas del día** — Total de ventas procesadas en el día
- **Productos con bajo stock** — Cantidad de productos por debajo del mínimo
- **DTE pendientes** — Documentos electrónicos por transmitir
- **Cuentas por cobrar** — Saldo total de clientes

### Gráficos
- **Ventas por mes** — Comparativa mensual
- **Ventas por sucursal** — Distribución por sucursal
- **Composición de ventas** — Facturación vs crédito fiscal

### Últimas ventas
- Lista de las transacciones más recientes
- Acceso directo al detalle de cada venta

## Funcionalidades

- **Selector de empresa/sucursal** en la barra superior para cambiar entre contextos
- Los indicadores se actualizan automáticamente
- Los montos pueden ocultarse según el permiso `view_amounts` del usuario

## Reportes rápidos

Desde el dashboard puede acceder a:
- Reporte de ventas
- Reporte de ventas diarias
- Ventas por categoría
- Ventas por POS
