# Manual de Usuario

Bienvenido al sistema de gestión empresarial **Nova SaaS**. Este manual describe el funcionamiento de cada módulo del sistema.

## Acerca del sistema

Nova SaaS es una plataforma multi-empresa diseñada para la gestión administrativa, contable y fiscal de negocios en El Salvador. Integra facturación electrónica (DTE) con Hacienda, control de inventarios, módulo POS, compras, cuentas por cobrar/pagar, contabilidad, gasolinera y recursos humanos.

## Cómo usar este manual

En el panel izquierdo seleccione el módulo sobre el que desea consultar. Cada sección explica:

- **Propósito del módulo**
- **Requisitos previos** (permisos, configuraciones)
- **Pasos para las operaciones principales**
- **Capturas de pantalla** (cuando aplique)
- **Integración con DTE** (para módulos que generan documentos tributarios)

## Convenciones generales

- Los montos monetarios se muestran en dólares americanos ($)
- Todos los formularios requieren seleccionar una empresa y sucursal (contexto)
- Las operaciones que generan DTE requieren configuración fiscal previa
- Los permisos se asignan desde el módulo de Roles en Seguridad

## Navegación

El sistema se organiza en módulos accesibles desde el menú lateral izquierdo:

- **Dashboard** — Indicadores principales
- **Ventas** — Punto de venta, historial, reportes
- **Compras** — Gestión de compras, gastos, cheques
- **Inventario** — Traslados, movimientos, kardex
- **Cuentas por Cobrar** — Estado de cuenta clientes, abonos
- **Cuentas por Pagar** — Estado de cuenta proveedores, abonos
- **Contabilidad** — Catálogo, partidas, cierres
- **Libros de IVA** — Libros de compras y ventas
- **Gasolinera** — Gestión de estaciones de servicio
- **Recursos Humanos** — Empleados, planillas
- **Seguridad** — Usuarios, roles, bitácora
- **Configuración** — Ajustes del sistema
