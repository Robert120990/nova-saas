# Cuentas por Pagar (CXP)

Gestión de cuentas por pagar a proveedores.

## Requisitos
- Permiso: `view_provider_statement`
- Permiso: `manage_cxp_payments`

## Consulta de Proveedor

1. Vaya a **Cuentas por Pagar > Consulta de Proveedor**
2. Seleccione el proveedor
3. Visualice:
   - **Saldo actual** del proveedor
   - **Documentos pendientes** con montos y fechas de vencimiento
   - **Historial de pagos** realizados

## Abonos / Pagos

### Registrar un abono a proveedor

1. Vaya a **Cuentas por Pagar > Abonos / Pagos**
2. Seleccione el **proveedor**
3. Seleccione la(s) **factura(s)** a pagar
4. Ingrese el **monto**
5. Seleccione el **método de pago**
6. Confirme el pago

## Reportes

### Saldos de Proveedores
- Listado de proveedores con saldo pendiente
- Totales consolidados

### Documentos por Pagar
- Detalle de cada documento pendiente
- Fechas de vencimiento
- Días de mora
